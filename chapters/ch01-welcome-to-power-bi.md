## Purpose

Meet Sabor Miami, a small group of food trucks around Miami, and its owner's first question. You will open a ready-made Sales file, learn the three views, read one table the way an analyst does, and finish with a card and a bar chart. This chapter also introduces the Zero Principle as the method for the whole book and shows where each later chapter sits in the Power BI workflow.

## Learning objectives

By the end of this chapter you will be able to:

- Explain in two sentences what Power BI Desktop does for a business and how it differs from the Power BI service.
- Name the five steps of the Power BI workflow (connect, prepare, model, visualize, share) and the chapter of this book that teaches each of the first three.
- Open a .pbix file, switch between Report, Table and Model view, and read the row count of a table from the status bar.
- Classify each Sales column as numeric or categorical and record it in a data dictionary.
- Build a card and a bar chart from a column and an aggregation, then save the report and reopen it.

## In this chapter

1. **Power BI starts with a question.** Start with the business question, then the data, then the chart.
2. **The Zero Principle: how analysts work.** Know the data before you analyze it, and analyze one column, then two, then three.
3. **Open the file and read the room: three views.** Three views, three jobs: Report to show, Table to inspect, Model to connect.
4. **Table, row, column: reading Sales like an analyst.** One row, one event: say what a row means before you count anything.
5. **Your first visuals: a card and a bar chart.** A visual is a question you can see: pick the field, pick the aggregation, read the answer.

## Try This ideas

Each section ends with a short "Try This" activity. A few of the ideas:

- **Power BI starts with a question.** Write one question Sabor Miami's owner might ask. List which parts of a paper receipt would answer it.
- **The Zero Principle: how analysts work.** Pick any table from your life (a phone bill, a class schedule). Write the objective, what one row means, and one column of each type.
- **Open the file and read the room: three views.** Open the file, click each view icon on the left, and write one sentence on what each lets you do. Find the view that shows rows.
- **Table, row, column: reading Sales like an analyst.** In Table view read ten rows of Sales. Write a one-line meaning of a row, classify three columns, and name one column you would not use for a question about tips. Then add a Table visual to the canvas and compare it with Table view.
- **Your first visuals: a card and a bar chart.** Make a bar chart of Truck by Sum of Amount. Switch Sum to Average, then to Count (Not Blanks). Write one sentence on what changed each time and why. Move and resize the visual, add and rename a page, save, close and reopen the file.

The chapter closes with a longer capstone Try This (about 18 minutes): "Know Your Data" on Sabor Miami Sales.
