## Purpose

A one-stop reference for the analysis steps of the Zero Principle: univariate, bivariate and multivariate. For each pairing of data types it names the Power BI visual, how to build it, what to read from it, and a Sabor Miami example. Use it any time you need to explain a visual in two sentences.

## Learning objectives

By the end of this appendix you will be able to:

- Choose the Power BI visual that fits one column, a pair of columns, or three or more columns.
- Build the visual and read what it shows about the business question.
- Explain any visual in two sentences, and say what it cannot tell you.

## In this appendix

1. **How to use this guide.** Start from your question, find the pairing, build the visual, and explain it in two sentences.
2. **Univariate: one column at a time.** Describe a number by its center, spread and shape, and describe a category by counts per value.
3. **Bivariate: two columns at a time.** Match the pair of data types (category and number, category and category, or number and number) to a visual.
4. **Multivariate: three or more columns.** Show one measure across two or more dimensions in a matrix or a chart with a legend and a slicer.
5. **Which visual?** Use one table that pairs each question type and data type with a visual and the chapter that teaches it.
6. **Explain a visual in two sentences.** Say what is compared and what it suggests for the business, then name what the visual cannot tell you.
7. **If Copilot is available.** Ask it to suggest a visual, then check what it builds against this guide and check the numbers against a card.
